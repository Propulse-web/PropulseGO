Gestión de usuarios

🔐 Usuarios gestionados por Supabase
Los usuarios se crean desde el panel de Supabase: Authentication → Users → Invite user.
Ingresás el email de la persona y Supabase le envía un link para que establezca su contraseña.
📋 Pasos para agregar un usuario:
1. Ir a supabase.com/dashboard
2. Seleccionar tu proyecto → Authentication → Users
3. Clic en Invite user → ingresá el email → Send invitation
4. La persona recibe un email con link para crear su contraseña y ya puede entrar a ProPulse
